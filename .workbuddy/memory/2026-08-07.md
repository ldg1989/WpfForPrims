## WpfForPrims - ViewA/ViewB 点击按钮不加载（Window 改 UserControl）

**症状**：MainWindow 点击"模块A"/"模块B"按钮，ContentRegion 区域不显示 ViewA/ViewB。

**根因**：ModuleA/Views/ViewA 和 ModuleB/Views/ViewB 的基类是 `Window`，而 Prism 的 `RequestNavigate` 要把视图放入 `ContentControl` 区域。`Window` 是顶级控件，不能作为 ContentControl 的子元素，导航静默失败。对比同项目正常工作的 UCA/UCB/UCC 都是 `UserControl`。

**修法**：将 ViewA、ViewB 的 XAML 根标签从 `<Window>` 改为 `<UserControl>`（去掉 Title，加 d:DesignHeight/DesignWidth），code-behind 基类从 `Window` 改为 `UserControl`。两个 .cs 文件已 import `System.Windows.Controls`，无需额外改动 using。

**改动文件**：
- ModuleA/Views/ViewA.xaml + ViewA.xaml.cs
- ModuleB/Views/ViewB.xaml + ViewB.xaml.cs

**验证**：`dotnet build` 通过，0 错误。模块注册（ModuleAProfile/RegisterForNavigation<ViewA>、ModuleBProfile 同理）和 VM 的 RequestNavigate 链路本身正确，无需改动。
